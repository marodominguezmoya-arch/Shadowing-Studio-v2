# Plans sur mesure — exemples réels (IA gratuite de Cloudflare)

Chaque exemple : la description dictée par l'élève → les **10 phrases personnalisées** de chaque semaine (en plus des 8 phrases d'autonomie communes). Générées par Llama 3.3 70B (écriture des phrases) puis Llama 4 Scout (traduction orale), sans retouche. Les erreurs visibles sont celles que ferait l'app aujourd'hui ; une IA haut de gamme (Claude) les réduirait nettement, surtout en darija.
